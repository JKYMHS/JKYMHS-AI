## 작업 규칙

1. 작업을 시작하기 전에 "참조" 열의 PRD·TRD·DB 절을 읽습니다.
2. 선행 작업이 끝나지 않은 작업은 시작하지 않습니다. 막히면 상태를 `[!]`로 바꾸고 사유를 적습니다.
3. 구현하다가 문서와 다르게 해야 하면, 먼저 문서를 고치고 나서 구현합니다. 계약(`AiCourseRequest`)을 바꿔야 하면 Spring 담당과 먼저 합의합니다.
4. 작업을 끝내면 상태를 `[x]`로 바꾸고, 완료 기준의 측정값이 있으면 비고에 적습니다.
5. **결정 지점**(◆)에서는 측정 결과를 정리해 팀에 보고하고, 결정이 나기 전에는 다음 단계로 넘어가지 않습니다.
